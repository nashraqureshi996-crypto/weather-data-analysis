# Historical Weather Data Analysis Dashboard

An exploratory data analysis (EDA) notebook and interactive Streamlit dashboard exploring global temperature, humidity, wind speed, and precipitation patterns over time.

## Key Findings
1. **Temperature & Humidity Inverse Relationship:** Warmer temperatures generally align with lower relative humidity.
2. **Upward Seasonal Temperature Trend:** Average temperatures steadily rise over the recorded date range.
3. **Right-Skewed Wind & Rainfall:** Most days experience calm winds and minimal rainfall, with occasional storm outliers.
